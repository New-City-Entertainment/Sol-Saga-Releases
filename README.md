# Sol Saga

A space sandbox adventure. This is where Sol Saga's builds and changelog live: the launcher
reads them from here.

## Get the game

Download the launcher. It installs the game, keeps it and itself up to date, and shows
what's new in each version. Saved games are kept apart, so updates never touch them.

### Mac

**[Download the Sol Saga Launcher for Mac](https://github.com/New-City-Entertainment/Sol-Saga-Releases/releases/download/launcher/Sol-Saga-Launcher.dmg)**

1. Open the disk image and drag **Sol Saga Launcher** onto Applications.
2. Open it. The first time, macOS asks before opening an app from the internet: open
   System Settings, then Privacy & Security, and choose **Open Anyway**.

For Apple Silicon Macs (M1 and later) on macOS 12 or newer.

### Windows

**[Download the Sol Saga Launcher for Windows](https://github.com/New-City-Entertainment/Sol-Saga-Releases/releases/download/launcher/Sol-Saga-Launcher.exe)**

1. Run it. Windows may say it protected your PC: choose **More info**, then
   **Run anyway**.
2. Choose **Install**. Sol Saga joins the Start menu (and the desktop, if you like) and
   Settings > Apps, where you can uninstall it. It installs for you alone, so it needs no
   admin rights.

For 64-bit Windows 10 and 11.

### Linux

**[Download the Sol Saga Launcher for Linux](https://github.com/New-City-Entertainment/Sol-Saga-Releases/releases/download/launcher/Sol-Saga-Launcher-linux.tar.gz)**

1. Unpack it, and run **sol-saga-launcher**.
2. Choose **Install**. Sol Saga joins your app menu; right-click it there to uninstall.
   Everything stays in your home folder, so it works on read-only systems like Bazzite.

For 64-bit (x86_64) Linux with Vulkan graphics.
