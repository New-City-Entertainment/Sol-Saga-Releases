# Sol Saga

A space sandbox adventure. This is where Sol Saga's builds and changelog live: the launcher
reads them from here.

## Get the game (Mac)

**[Download the Sol Saga Launcher](https://github.com/New-City-Entertainment/Sol-Saga-Releases/releases/download/launcher/Sol-Saga-Launcher.dmg)**

1. Open the disk image and drag **Sol Saga Launcher** onto Applications.
2. Open it. The first time, macOS asks before opening an app from the internet: open System
   Settings, then Privacy & Security, and choose **Open Anyway**.
3. The launcher installs the game, keeps it and itself up to date, and shows what's new in
   each version. Saved games are kept apart, so updates never touch them.

For Apple Silicon Macs (M1 and later) on macOS 12 or newer.
